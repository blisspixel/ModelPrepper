Keep verified copies of open-weight models on your own disks.

Usage: modelprepper.exe [OPTIONS] <COMMAND>

Setup:
  config        Create or check a vault configuration file
  init          Initialize the local catalog and adopt empty storage directories
  status        Inspect catalog, preserved copies, and disk identities offline

Review a source:
  resolve       Resolve a public model to a pinned commit and inspect its
                license evidence
  propose       Inspect a public source and persist its exact evidence and
                destination
  proposals     Browse saved source reviews offline
  decide        Record a final review decision. Transfer approval is not
                available yet

Local copies:
  verify-local  Hash a local folder against a resolved commit. Reads only;
                nothing is copied
  adopt         Copy or move a verified local folder into the vault
  local         Read-only inventory of local runtime stores

Preview:
  plan          Preview an untrusted local inventory. Never authorizes model
                transfers

  help          Print this message or the help of the given subcommand(s)

Options:
      --pretty         Indent JSON. Also used automatically when stdout is a
                       terminal and JSON is selected
      --json           Print JSON even when stdout is a terminal
      --quiet          Suppress progress lines
      --color <COLOR>  Colorize text verdicts. JSON is never colored [default:
                       auto] [possible values: auto, always, never]
  -h, --help           Print help
  -V, --version        Print version

First run:
  modelprepper config init --output c.toml --catalog catalog --volume models
  modelprepper init --config c.toml
  modelprepper resolve --repo <org/model>
  modelprepper propose --config c.toml --repo <org/model>
  modelprepper verify-local --repo <org/model> --path <dir>
  modelprepper adopt --config c.toml --plan <id> --path <dir> --copy
